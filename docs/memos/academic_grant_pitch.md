# The Uninspectable Message: Research Collaboration Memo

## Abstract

We study whether TFLOW / Thought Flow-style multi-agent systems expose hidden communication capacity through transient LoRA perturbations. Unlike text-based MAS, where inter-agent messages are visible in the context window, TFLOW compiles sender hidden states into temporary, low-rank receiver weight updates. We introduce a defensive measurement framework for testing whether task-independent signals can survive semantic constraints, implementation noise, and task-conditioned anomaly filters, mapping the resulting capacity–detectability Pareto frontier.

- Security paper or workshop submission.

- Reference implementation for spectrum, fusion-gate, provenance, and Grassmannian drift auditing.
