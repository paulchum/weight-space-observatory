# Responsible Research Boundary

This project is defensive. It contains one bounded local red-team fixture for
validating whether telemetry detects FP32 LSB weight injection. It does not
contain a deployment covert-channel protocol, keyed extraction protocol,
prompt-search steganography tooling, monitor-bypass logic, or evasion tuning.

Contributions should focus on monitoring, measurement, provenance, anomaly detection, and audit reporting.
