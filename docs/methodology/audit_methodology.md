# Audit Methodology

1. Map visible and non-text communication surfaces.
2. Instrument adapter / LoRA / fusion telemetry.
3. Build task-conditioned benign baselines.
4. Measure singular spectrum, rank, fusion entropy, and subspace drift.
5. Analyze telemetry against calibrated metric bands and record anomaly findings.
6. Run synthetic capacity-detectability benchmarks when evaluating observability limits.
7. Generate an executive communication-surface risk report.
